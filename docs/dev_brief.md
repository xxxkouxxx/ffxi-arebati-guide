# Orca開発依頼書 — FFXI Battle Motion Studio

## 目的
FFXIの攻略記事と実際の討伐YouTube動画を、各ジョブの行動タイムライン・位置関係の模式図に同期させる学習用Webアプリを構築する。「動画のこの時点で誰が何を、なぜ行うか」を理解できることが最優先。初期対象はArebati Veng+25の2戦目。

## 正本・参考資料

- `FFXI_Battle_Motion_Studio_v02.html`（v0.2同期PoC。設計・動作確認用の参考であり完成品ではない）
- 原記事 https://jinko0914.seesaa.net/article/513963925.html

## 役割とオーケストレーション
- Orca：全体設計・タスク管理・進行・検証証跡・Human Gate運用の責任者
- Claude Opus 5.5：UI/UX、時刻同期エンジン、戦術表示の主実装者
- Codex等の別担当：テスト・独立レビュー。実装者の自己承認は禁止
- HERMES：必要な場合のみ運用要件を整理。既存環境の変更は禁止
- ユーザー：構成選択、次段階の開始、外部公開、ゲーム環境連携を承認

## 承認済み作業範囲（独立したローカルPoCのみ）
1. v0.1 / v0.2 HTMLを監査して表示・挙動を維持したうえで、保守しやすく整理する。
2. YouTube IFrame Player APIによる2つの視点切り替えと動画操作を実装する。
3. 動画再生時刻を正本に、イベントタイムライン・ジョブ別強調・模式図を追従させる。タイムラインから動画への逆方向シークも実装する。
4. 同期はまず手動で行う。イベントと動画内の時刻を2点以上マッピングし、点間だけ補間する。未登録範囲・未確認時刻を実測扱いしない。対応付けの削除・修正とJSON入出力を用意する。
5. 動画A/Bの時刻対応付けは完全に分離する。1戦目/2戦目、動画時刻/130秒圧縮デモ時刻を明示する。
6. ナイト、踊り子、赤魔道士、コルセア、吟遊詩人、獣使い／ペットの行動・対象・理由を表示する。
7. 出典区分を必須にする（記事に記載／映像で目視確認／演出用仮定／未確認）。位置・HP・アビリティ使用時刻を憶測で確定させない。
8. 埋め込み不可・YouTube API取得失敗・ネット切断時も、元動画へのリンクと手動デモを維持する。
9. Mac mini上のローカルHTTPサーバー、Chrome/Safari、スマホ幅で動作確認する。

## 禁止事項・安全条件
- FFXI、Ashita v4、DAT、チャット設定、ゲームプロセス、他プロジェクトのファイルを変更しない。
- YouTube動画の無断ダウンロード・複製、再生制限の回避、広告や標準コントロールの隠蔽は禁止。公式プレイヤーを利用する。
- 位置推定・動画OCR・字幕抽出・自動認識・外部AIへの動画送信は追加承認が出るまで対象外。
- 実データではないシミュレーション時刻、移動座標、HP値を事実として表示しない。
- 外部公開・リポジトリへのpush・破壊的ファイル操作・既存環境への導入はしない。
- 新規依存パッケージやAPIキー利用が必要な場合は、その理由・影響を報告して承認を待つ。

## Human Gate
- Gate A：技術調査の結果、データ構造、同期方式、YouTube埋め込みに関する制約を提示。実装方針を承認。
- Gate B：実際の2動画を対象に、手動同期の動作確認と誤差・未確認区間を提示。次段階への移行を承認。
- Gate C：自動行動検出、3D再現、一般公開、FFXI環境との連携は別途承認があるまでHOLD。

## 完了条件
- 動画A/B切り替えと再生・停止・シークができる。
- 少なくとも2つの手動同期点の登録・変更・削除、時刻の双方向ジャンプができる。
- 未設定・1点のみ・2点以上・順序矛盾・プレイヤーエラー時に適切な状態が出る。
- 同期点が映像に基づく目視記録か演出用か、画面上でもJSONでも判別できる。
- JSON入出力、再起動後の復元、モバイル表示、既存デモへのフォールバックを確認する。
- 実動画での検証ができない場合は、その範囲を明記して未完了として報告する。

## 返却形式
1. Result（達成・未達・Gate）
2. Changes（変更したファイルと要点）
3. Verification（テスト・実動画での実測確認・未確認事項）
4. Risks / Open Items（ライセンス・API制約・精度・時刻不明）
5. Human Gateで必要な判断
6. NEXT（承認後の次の1ステップ）
